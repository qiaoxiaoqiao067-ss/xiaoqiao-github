# ADX日报首页同步

首页从已授权工作区的云端记录读取日报，不能直接读取电脑桌面。日报与市场榜单分别存取：日报保留原有投放/TikTok各Top100、12平台各Top50口径，不混入日50/周300/月500分析。

## 既有每日任务

Codex自动任务`adx`（ADX每日监测与日报）仍在北京时间10:30执行，原聊天与采集范围不变。每次采集结束（包括登录失败）保存采集清单，然后执行仓库发布脚本：

```sh
cd /Users/xiaoqiao/workbench
npx tsx scripts/sync-adx-daily-brief.ts --owner 77fdc7c6-5c17-4fa4-8a83-b00a478b0579 --root /Users/xiaoqiao/Desktop/ADX每日监测
```

脚本自动读取仓库现有服务端环境，不需要将密钥写入命令或任务提示词。`--dry-run`可预览。根据数据日/执行子目录生成固定记录名；同一清单和正文重复同步不产生新记录。旧文件不修改。无明确时间或日期不一致的清单拒绝发布，并以非零退出码提醒检查。

清单至少包含：`status`、`requested_data_date`、`data_date`（未核验为null）、`checked_at`（含时区）或`generated_at_shanghai`。成功日报应为同目录`日报_YYYY-MM-DD.md`，标题含真实数据日。市场信号从第二节的编号段落提取“事实、判断、行动”，格式不匹配时保留全文，不生成替代内容。

## 首页行为与权限

- 只读取最近采集记录和最近成功日报；即使持续失败，旧成功日报仍可阅读，日期不改写。
- 10:30前预期数据日为北京时间前两天，10:30后为前一天；任务还未发布则显示待更新，不能据此推断具体故障。
- 首次打开、页面重新聚焦、可见时每5分钟检查更新，亦可手动刷新。
- 延用`market_data`查看权限和工作区所有者范围；未获权限不显示卡片，不新增成员权限。
- 云端已发布日报在本机离线时仍可阅读；新增日报依赖既有本机自动任务成功执行与发布。同步失败由原任务报告，并以首页日期提示未更新。

## 市场加载优化

目录保持全量可选，原表保留。浏览器只加载当前期与对比期中相同榜单的TopN及版本/映射信息；切换月份按需读取，并按文件ID与更新时间缓存。原表在服务端先完成日期异常检查，不能因截取TopN漏掉榜外未来日期。普通无参数分页接口继续返回全量原始行；样本模式仅供分析。
