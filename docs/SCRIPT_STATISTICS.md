# 本地化字数统计与报价

入口是首页快捷区「字数统计」、项目详情「字数统计与报价」和剧本文件行「统计此版本」。沿用 `/localization` 地址，独立统计不要求先建项目。

## 默认统计口径

- 只计中文汉字，不计英文、阿拉伯数字、标点或空白。
- 全本从实际分集正文开始，包含场景、动作、人物标签、画面文字与对白；前置简介、大纲、人物小传不计入。支持手动选择正文起点。
- 发声台词排除说话人标签与表演提示，默认包括电话、语音、旁白、VO、OS及明确机器播报。
- 短信、字幕及原文明示的画面文字单列，勾选后可加入台词报价；按原稿出现次数统计，可在逐行核对中排除复用项。
- 中英双语稿识别中文侧；中文台词重复出现时按每次出现计数，不能全局去重。
- 可按集段筛选，默认单价每千字120至150元，不足千字按实际字数折算，金额按分舍入。也可改为按全本报价。

## 复核和追溯

DOCX直接读取OOXML，保留软换行和表格顺序，接受新增修订，排除删除、移出、隐藏内容和批注。无法可靠读取的内容、无标签台词或括号内歧义不能默默视作可信统计。

逐行核对可指定分类、修正计数正文，原始文字保持可见。复制报价、CSV和统计报告采用同一组结果；待复核结果明确带有标记。报告保存文件SHA256、来源版本、规则版本、集段、单价和人工修正，并可由用户主动保存至项目资料库的「字数统计报告」。不修改合同金额或项目阶段。

DOCX、TXT、Markdown在浏览器处理，原件最大50MB。PDF、旧版DOC临时服务端处理上限4MB；已有项目原件上限50MB，下载有流式限制及原件大小校验。PDF/OCR和旧版DOC必须核对识别完整性，不能直接当作精确报价。

## 旧功能退役

旧剧本翻译表单、任务状态操作及专用hook已撤下。`/api/localization`的POST、PATCH、DELETE返回410，历史任务GET仅供有权限的工作区只读访问。历史稿件、公共文件表、项目合同、付款信息、项目阶段及围读排期保持原业务用途。

市场看板剧名中文化的页面、接口和已有映射独立保留。

## 验证

`npm run test:script-statistics` 验证计数、修订、软换行、表格、双语、括号独白、选集与报价。`tsx --test tests/script-statistics-api.test.ts` 验证原件访问授权、路径与大小限制、解析失败和只读历史。

真实稿件不提交仓库。可通过环境变量 `SCRIPT_STATISTICS_FIXTURE_MANIFEST` 指向本机外部清单追加回归；清单中的段落文本会在内存构造DOCX，验证提取至计数完整链路。
