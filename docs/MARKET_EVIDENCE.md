# 市场证据使用说明

## 录入与核验

在「市场数据看板 → 榜单与趋势 → 外部信号 → 行业报告与内容核验」点击新增证据记录。支持行业报告、作品核验、平台公告和调研记录。粘贴已有原文/观看记录，填写来源链接；来源链接不会自动读取。报告附件入口支持PDF、DOCX、TXT、Markdown的原件上传与文字解析。

事实、人工判断、建议行动分别填写。核验状态初始为待核验；来源名称、原文位置、适用范围和可核查事实完整后，选择已核验并勾选确认。地区、制作类型不明确时写未知，不能以排名代替商业效果。这里的核验是人工来源核对，不保证判断正确。

适用统计期留空表示通用，否则填写例如2026年10月。只读成员可查看和复制，市场编辑成员才可保存。编辑后再次标为已核验需重新勾选确认。编辑/归档内选择已归档可隐藏记录，勾选显示已归档可重新打开并恢复。

## 月度研判附带旁证

切换到月榜与正确对比期，在「研究与行动 → 市场研判存档」展开选择已核验旁证。仅列通用或适用当期记录，最多20份，可刷新或继续加载。保存时校验榜单与证据版本，任何变化提示重新选择，不覆盖人工输入。

存档固定当时的原文、事实、判断、行动与来源版本，后续修改或归档原证据不改旧存档。旁证独立呈现，不自动改变榜单规则结论；复制存档正文会包含旁证和来源。旧存档没有旁证也可以照常打开。

## 数据边界

证据复用现有记录容器，标记市场研究:evidence，服务端按工作区和模块权限隔离，排除榜单目录与统计。没有更改ADX每日采集任务、TopN口径或原榜数据。还未提供的报告不补写；原片未观看不标记为内容已核验。

## 报告附件与出处

在「行业报告与内容核验」打开「报告附件与出处」，可上传20MB以内PDF、DOCX、TXT或Markdown。文件直接上传到工作台存储，解析失败也保留原件，列表中可重试解析。原文件不可被新上传覆盖，重新上传生成独立附件。

PDF显示物理页码（可能与报告印刷页码不同）；Word显示提取段落，不冒称原页码；TXT/Markdown保留原始行号，支持UTF-8。正文搜索后选择具体页/段/行，把要引用的连续原文填入精确引用框，点击「采用此出处」进入证据草稿。原文与人工判断分开，不可改写原文后仍冒称精确引用。服务器会重新核对出处。

扫描页或图片没有文字层时明确标记，当前不做OCR；全空或损坏文件不会生成成功正文。正文大于约1.5MB或PDF超过300页时要求拆分，不静默截断。原附件链接临时有效，可重新生成；PDF链接带页码，能否直接跳页取决于浏览器PDF阅读器。

## 关联具体选题

证据保存并核验后，展开记录点击「关联具体选题」，选择既有选题，填写支持选题/提示风险/背景参考及理由。也可以在「选题情报」每行点击「市场证据」，核对来源后关联。

关联保留证据当时快照（含附件出处与校验值），不改变选题原文和状态。来源后续修改或归档时显示提醒；需要人工明确点击更新为当前核验版本。解除关联保留旧快照，可以选择仍已核验的来源恢复。原来源归档后不能作为新的已核验证据关联。

查看关联同时需要市场和选题查看权限，新增/更新/解除需要市场查看及选题编辑权限；不会因为可以看选题就自动获得市场报告访问权。

## 将报告用于每月研判

在「市场数据看板 → 榜单与趋势 → 研究与行动」选择月份和对比月份，打开某个题材的「结合报告完善本条研判」。勾选已核验且适用本月的证据，选择支持判断、提示反例或背景参考，并说明来源是独立来源、同源复述还是尚未确认。关键词相关只是查找提示，不代表系统已确认内容相关。

点击「整理联合研判草稿」预览由既有事实、判断和行动组合的草稿；它不是AI通读完整报告后的分析。预览不会覆盖编辑文字，只有点击采用才替换。完善本月结论、选题要求、投放验证、调整条件，核对范围与边界后确认应用。

确认内容会进入月度总览、研究行动与导出简报，每条均可展开「查看本条依据与出处」。同源复述不算第二份独立验证；有反例优先处理分歧，不根据标签或报告热度自动提高预算。证据或榜单版本变化后暂停应用旧研判，打开旧稿重新核对后确认。

保存月度存档时同时冻结当前有效联合研判及引用；编辑当前研判不会改旧存档。复制存档包含联合研判、原文与版本。新建待评估研究方向时同时保存联合研判文字，并逐条关联对应证据；已有选题不自动改正文或状态。若新选题创建成功但证据关联失败，会分别提示，可到该选题的市场证据面板补齐。

## 月度建议用于已有选题（2026-11-12）

当前版本已合并主分支并部署，正式域名真实操作验收通过。入口：https://xiaoqiao-github.vercel.app/discover → 对应月份 → 选题「依据与验证」。

1. 市场数据看板 → 榜单与趋势 → 研究与行动，找到已确认的报告联合研判。点击「关联已有选题 / 查看验证进度」。
2. 搜索并选择选题，写明适用理由，点击「关联所选已有选题」。系统不会创建新选题，不会改写选题正文或决策状态。同一研判再次关联相同选题保留原记录与进度。
3. 内容与选题核验、投放对照验证、后续复核与调整默认均为待验证；可调整具体动作和可选日期。选择已完成时必须记录实际结果，验证失败或信息不足也应如实记录。只有保存成功才更新完成比例。
4. 选题情报 → 对应选题「依据与验证」可查看相同计划。展开「查看关联时的月度结论与原文出处」查看本月结论，再展开依据看到原文位置与报告附件。
5. 已解除的关联保留历史，可恢复。研判或来源更新时提示复核，保留关联时版本和验证结果；本期不提供自动换版，不把历史验证结果无条件移植到新建议。
6. 并发编辑遇到版本冲突时保留当前输入，请先复制输入，刷新核对后重新编辑。市场查看及选题查看权限才能读取；市场查看及选题编辑权限才能关联和修改验证。其他账号实机验收应独立执行。

存储为 `市场研究:idea-review` 记录，不计入榜单统计。关联标识按工作区、已有选题、研判ID生成；更新采用记录版本校验。


## 验证结果反馈后续月度研判

本节功能已合并主分支并部署，正式网站页面与真实未完成数据验收通过。入口：https://xiaoqiao-github.vercel.app/market-data → 榜单与趋势 → 研究与行动 → 此前建议效果复盘。

1. 选题「依据与验证」中更新验证事项。完成后填写实际结果，再选择建议效果（支持原建议、需要调整、证据不足）和效果判断依据。保留未评估时不作为月度支持证据；重新打开验证时清除旧效果判断，实际结果保留。
2. 市场数据看板 → 榜单与趋势 → 研究与行动 → 此前建议效果复盘。选择反馈月份或「查看下月复盘」，查看原建议、实际结果和调整理由，按效果筛选。此月份不改变榜单统计期，新月份未导入榜单也能预览验证进度。
3. 导入目标月份榜单后，在对应题材「编辑报告联合研判」中选择可采用的已评估结果，核对原建议和结果，整理草稿、人工调整并确认后才影响当月研判。草稿不会自动覆盖编辑内容。
4. 只允许原建议月份早于本月，且完成/结果修改时间截至本月底的验证。时间按服务器UTC月份截断。解除关联、选题已删除、未完成、未评估、结果缺失、题材不符和版本变化均不能采用。
5. 支持仅说明该条建议在记录范围内得到支持；反例优先提示调整，证据不足不计支持。不合成全市场成功率，不自行改动选题决策或投放预算。
6. 已确认研判、复制文本、导出「建议验证反馈」表及新存档保留当时的原建议、实际结果、效果说明、完成时间与来源版本。来源之后修改会提示复核，旧存档继续保留。

当前真实记录尚未完成验证时，页面应显示待完成或待评估，不能演示为已证明有效。
