# 团队验证任务权限验收（2026-11-12）

## 结论与边界

服务端权限规则、正式库成员配置和共享数据读取已检查。尚未取得成员本人登录会话，不能宣称已完成成员账号的浏览器端端到端验收。

本轮不改变成员角色或模块授权，不代登录真实成员，不生成成员登录凭证，不写入正式业务数据。

## 已执行的检查

- 正式库只读：对每名成员调用现有权限解析器；有权成员读取同一owner下的相同验证任务ID。与检查前比对，成员角色和权限记录完全不变。
- 新增11项实际路由逻辑测试：仅认证身份和数据库使用隔离夹具，使用真实GET/PATCH路由及真实工作区权限解析器；不把模拟认证当作真实登录。
- 覆盖：401未登录；协作者保存日期/结果；所有者和只读者读取相同保存记录；只读/停用/无模块/未授权拒绝保存；跨工作区404；读取后撤权仍拒绝写；过期版本和数据库竞争409；无结果不能完成；解除关联或选题删除停止展示。
- 81项市场/权限回归测试通过；TypeScript、定向ESLint通过。本轮没有修改产品代码，因此不需要重新部署产品。
- 首页和任务中心读取同一/api/tasks/validation；同浏览器保存通知即时刷新，跨设备重新聚焦或可见页面60秒轮询获取更新。不是跨设备即时推送。

## 待完成的真实成员验收

1. 首页查看3项验证提醒，点击进入任务中心。
2. 打开一项建议，核对是否有“更新截止日期与验证结果”。
3. 使用可恢复的临时日期保存；记录原值，不虚构工作完成或效果。
